Calendar works instantly · Timer needs 1-time Shortcut setup ↗
  1. Open Shortcuts app → + new shortcut.
  2. Name it exactly Sleep Wake.
  3. Add action Start Timer. Tap its duration → choose Minutes, then set the number field to the shortcut's Shortcut Input (magic variable).
  4. Done. Button above now starts a timer for minutes-until-wake — fires alarm sound at wake (loud, overrides silent).

Timer = single loud fire, no snooze. iOS has no web/Shortcut way to set a true repeating alarm.
